Research Scope

This prototype addresses financial fraud detection through a structured experimental pipeline aligned with the project proposal.

01

Data Preparation

Cleaning, feature engineering, class balancing, and account-legitimacy enrichment across multi-part transaction records.

02

Model Comparison

Benchmarking Logistic Regression, Decision Tree, Random Forest, and XGBoost using accuracy, precision, recall, F1, and ROC-AUC.

03

Risk Monitoring

Interactive transaction scoring with fraud probability estimates and categorical risk levels for analyst review.

Methodology

  • Dataset: CiferAI/Cifer-Fraud-Detection-Dataset-AF (Hugging Face)
  • Preprocessing: Feature engineering, standardisation, and 50/50 class balancing
  • Key features: Transaction attributes and account legitimacy indicators
  • Evaluation: Stratified train/test split with held-out test metrics
  • Selection criterion: Highest test accuracy for production deployment

Research Outputs

  • Comparative analysis of four supervised classifiers
  • Trained and serialised production-ready fraud model
  • Interactive monitoring dashboard (this application)
  • Reproducible training pipeline and evaluation artefacts
